# Lily AI Assistant - Releases

This repository contains the official release files for Lily AI Assistant, a multi-modal AI desktop companion with voice, text, and full screen access.

## 🚀 Download Lily AI Assistant

Visit our [official website](https://lily-ai.com) to download the latest version of Lily AI Assistant for your platform.

### Supported Platforms

- **macOS** (Intel and Apple Silicon)
- **Windows** (10/11)
- **Linux** (AppImage)

## 📦 Release Files

Each release includes platform-specific installers:

- `Lily.AI.Assistant-1.0.0.dmg` - macOS (Intel)
- `Lily.AI.Assistant-1.0.0-arm64.dmg` - macOS (Apple Silicon)
- `Lily.AI.Assistant.Setup.1.0.0.exe` - Windows
- `Lily.AI.Assistant-1.0.0.AppImage` - Linux

## 🔒 Security

All release files are digitally signed and verified. Download only from official sources.

## 📋 System Requirements

### macOS

- macOS 10.15 (Catalina) or later
- 4GB RAM minimum, 8GB recommended
- 500MB available disk space

### Windows

- Windows 10 version 1903 or later
- 4GB RAM minimum, 8GB recommended
- 500MB available disk space

### Linux

- Modern Linux distribution with glibc 2.28 or later
- 4GB RAM minimum, 8GB recommended
- 500MB available disk space
